# 生存服务器

Eternal Parkour 可以与正常游戏一起运行在生存（SMP）服务器上。本页说明插件会改动什么、如何保护玩家的物品，以及需要检查哪些设置。

## 插件会改动什么

- **两个额外的世界。** 方块跑酷在 `witp` 中进行，鞘翅跑酷在 `iep` 中进行。两者都是空的虚空世界，插件会在每次重启时删除并重新创建。生存世界不会被改动；唯一的例外是大厅模式，它会在管理员通过 `/ipp lobbygm` 设置的区域内生成跑酷。
- **默认设置下不会强制玩家加入**：玩家只能通过菜单或命令进入跑酷。请保持 `bungeecord.enabled`（`config.yml`）和 `join-on-join`（`elytra/config.yml`）为 `false`，任意一个开启都会让所有玩家在进入服务器时直接加入跑酷。
- **聊天不受影响**，除非玩家在设置菜单中选择了仅大厅或仅玩家的聊天模式。

## 玩家的物品

玩家进入方块或鞘翅跑酷时，插件会把其背包、位置、游戏模式、饥饿值、飞行状态和药水效果备份到 `plugins/EternalParkour/backups/`，然后发放跑酷物品。离开时一切都会归还，备份随之删除。

- **服务器崩溃。** 如果服务器未正常关闭，备份会留在磁盘上，并在玩家下次进入服务器时自动恢复，玩家会收到提示，无需管理员操作。手动恢复方法见[故障排查](./troubleshooting#背包没有恢复)。
- **传送命令。** 如果玩家在跑酷中使用 `/home`、`/spawn`、`/tpa` 等命令，会离开跑酷并取回物品，并停留在命令传送到的位置。
- **跑酷物品无法带出。** 跑酷中发放的物品都带有标记，包括菜单物品（其中一个是屏障方块）和无法破坏的鞘翅。不在跑酷中的玩家持有这些物品时会被移除：进入服务器时、每隔几秒、以及尝试拾取或放置时。

::: warning 请保持开启背包保存
在生存服务器上，`options.inventory-saving` 必须保持为 `true`。关闭后磁盘上没有备份，一旦崩溃，所有正在跑酷的玩家都会丢失背包。
:::

## 推荐设置

| 设置 | 文件 | 建议 |
| --- | --- | --- |
| `options.inventory-handling` | `config.yml` | `true`：玩家获得干净的跑酷物品栏，自己的物品被安全保存。 |
| `options.inventory-saving` | `config.yml` | `true`（见上文）。 |
| `focus-mode.enabled` | `config.yml` | 如果服务器有拍卖行、交易、出售等插件，请设为 `true`。它会在跑酷中阻止其他命令，使跑酷物品无法被出售或交易。允许使用的聊天命令请加入 `focus-mode.whitelist`。 |
| `permissions.enabled` | `config.yml` | `false` 表示所有人都可以使用全部玩家功能；设为 `true` 后可用 `ip.*` 权限节点控制。管理命令始终需要 `ip.admin`（鞘翅跑酷的管理命令需要 OP）。 |
| `enabled` | `rewards-v2.yml`、`elytra/rewards.yml` | 奖励默认关闭。周期奖励每隔若干分数就会重复发放，因此金钱和物品奖励请设得小一些，以免被刷。 |
| `modules.elytra` | `config.yml` | 不需要鞘翅跑酷及其世界时设为 `false`。 |

## 其他插件

- **反作弊。** 鞘翅跑酷会给玩家加速，方块跑酷中玩家也会快速移动。如果反作弊在这些世界中误判，请豁免 `witp` 和 `iep` 世界。
- **战斗退出。** 加入跑酷会立即把玩家传送走。如果服务器有 PvP，请在战斗插件中禁止战斗期间使用 `/ep`、`/parkour`、`/ipp` 和 `/iep`。
- **计分板与 Tab 列表。** 显示跑酷计分板时，其他插件的名称标签和 Tab 颜色对该玩家不生效；玩家离开跑酷或在跑酷设置中关闭计分板后即会恢复。
- **世界管理与地图。** 不要把 `witp` 或 `iep` 导入 Multiverse、地图渲染或世界备份，它们每次重启都会被重新创建。
